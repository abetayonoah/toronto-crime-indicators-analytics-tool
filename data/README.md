# Dataset

## Overview

The original Toronto Crime Indicators dataset is not included in this repository because of its large file size and licensing considerations.

## Download

The dataset can be downloaded from the official Toronto Police Service Open Data Portal:

https://data.torontopolice.on.ca/

## Usage

After downloading the dataset, place the CSV file inside this `data` folder before running the application.

Expected file:

```
data/Toronto_Crime_Indicators.csv
```
