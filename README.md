# Toronto Crime Indicators Analytics Tool

A Python and Streamlit analytics application developed to transform large-scale Toronto crime data into accessible insights for public-safety planning and operational decision-making.

## Project Overview

This graduate team project analyzed 474,819 Toronto crime incident records spanning 2014–2026 across 31 variables. The application covers data loading, cleaning, analysis, visualization, automated testing, and an interactive Streamlit dashboard.

The solution was developed using Scrum across two sprints, with GitHub feature branches, pull requests, peer reviews, Test-Driven Development, and intentional refactoring.

## Business Problem

Public-safety professionals and city stakeholders need an accessible way to:

- Monitor monthly and yearly crime trends
- Compare crime activity across police divisions
- Identify high-risk premises and locations
- Explore crime patterns without writing code
